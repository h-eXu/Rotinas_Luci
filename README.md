# Rotinas · Luci Cordeiro

App para montar as rotinas de cada casa: pessoas, funções, dias de trabalho, tarefas e quadros de cor (panos e esponjas), e compartilhar as folhas em PDF para imprimir.

- Funciona no celular (Android) e abre sem internet depois da primeira vez.
- Os dados ficam guardados só no celular de quem usa. Use **⋮ → Fazer backup** para guardar uma cópia.
- Este repositório não contém dados de clientes.
